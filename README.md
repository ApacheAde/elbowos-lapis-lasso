# Lapis Lasso

Full-colour Python 3 neon grappling-swing arcade for ElbowOS.

Swing a gold lasso between azure anchors to snag floating orbs.
Space attaches / releases. A/D or arrows nudge velocity.

## Play
```bash
pip install -r requirements.txt
python3 lapis_lasso.py --play
```

## Record a 9:16 reel
```bash
python3 lapis_lasso.py --record
```
Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
